# Starify — бот пополнения Telegram Stars

## Как работает
1. Клиент выбирает получателя (себе или другу по @username) и количество звёзд.
2. Платит через Platega (СБП или крипта). Бот сам проверяет оплату каждые 10 секунд.
3. После оплаты админам приходит заказ с кнопками:
   - **✋ Беру в работу** — останавливает таймер, отправляешь вручную на fragment.com и жмёшь «Отправил».
   - **⚡ Отправить автоматически** — бот покупает звёзды через Fragment.
   - **✅ Уже отправил вручную**.
4. Если админ ничего не нажал за `ADMIN_TIMEOUT_SEC` (5 минут), бот отправляет звёзды сам.

Если результат автоотправки неизвестен, заказ получает статус «проверяется», а админам приходит уведомление. Бот **никогда не повторяет** такую оплату сам, чтобы не заплатить дважды.

## Запуск
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```
Настройки лежат в `.env` (образец: `.env.example`).

## Автодоставка (Fragment)
```
.venv\Scripts\pip install "fragment-api-py==14.4.1"
```
Версия 14.4.2 была вредоносной (крала средства), не ставь её.
Используй **отдельный** TON-кошелёк с небольшим балансом, а не основной.
Заполни `FRAGMENT_SEED`, `FRAGMENT_API_KEY`, `FRAGMENT_COOKIES` и поставь `FRAGMENT_ENABLED=1`.

## Команды админа
`/admin`, `/stats`, `/price 1.6`, `/orders`, `/balance`
